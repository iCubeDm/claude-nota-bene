# M4 research: prototype behaviour to match

The prototype lives in `prototype/server.mjs` (S) and `prototype/public/index.html` (H). Line numbers are as of 2026-10-25. The SDK is 0.3.310, and every API below exists in its `sdk.d.ts`.

## 1. Session picker
- **GET /sessions** (S:380-391) calls `listSessions({ limit: 300 })` across all projects and returns `{ current, root, sessions: [{ id, title: titleOf(x)||'', at: lastModified, size: fileSize, cwd: x.cwd || cwdOf(id) }] }`. Entries without a cwd are dropped ("can't be resumed in the right folder").
- **titleOf** (S:146): the first of `customTitle`, `summary`, `firstPrompt` that is non-empty and does not start with `/`.
- **cwdOf** (S:126-144) finds `~/.claude/projects/*/<id>.jsonl`, reads the first 262144 bytes, applies the regex `/"cwd":("(?:[^"\\]|\\.)*")/` and JSON-parses the match. Results are cached in a Map, null included.
- **UI** (H:1401-1450):
  - The menu is 460 px wide.
  - Groups: this project first, with the `.here` header; the other folders follow in first-appearance order.
  - The first item is `newHere`.
  - Each item shows the title or `untitled`, and a meta line `id8 · ago(at) · kb(size)`. The current item gets ` · open now` and cannot be clicked.
  - The filter is autofocused and matches substrings of `(title+' '+cwd).toLowerCase()`. It never hides the "new" item and hides empty groups.
  - `ago`: under 1 min gives justNow, under 60 min gives minAgo(m), under 1440 min gives hAgo(round(m/60)), otherwise a date (`day:'numeric', month:'short'`).
  - `kb`: above 1e6 bytes gives `x.x MB`, otherwise `round KB`.
  - `short()` replaces `/Users/<x>` with `~`.
- **i18n (ru / en)**:
  - sessions: Сессии / Sessions
  - sessTip: «Открыть другую сессию Claude Code — из любой папки (как claude --resume)» / "Open another Claude Code session, from any folder (like claude --resume)"
  - openQ(t): «Открыть сессию «${t}»?» / "Open session “${t}”?"
  - newQ: «Начать новую сессию?» / "Start a new session?"
  - moveQ(dir): «\n\nСессия из другой папки: окно переключится на проект\n${dir}\n(дерево файлов, доступ к файлам и рабочая папка агента).» / "\n\nThis session is from another folder: the window will switch to the project\n${dir}\n(file tree, file access and the agent's working folder)."
  - switchWarn: rewrite for the in-process switch, keeping the second sentence: «Не держи эту же сессию открытой в терминальном claude: история перемешается.» / "Don’t keep this same session open in a terminal claude: the history would get mixed up."
  - switching: переключение… / switching…
  - switchFail: «Не удалось переключить: » / "Could not switch: "
  - loading: загрузка… / loading…
  - untitled: (без названия) / (untitled)
  - openNow: « · открыта сейчас» / " · open now"

## 2. Titles
- **Server:** `title = titleOf(await getSessionInfo(id, { dir: root }))`. It is refreshed with the stats and set to null on `conversation_reset`.
- **Web:** the chat tab label is the title or `t('chat')`, and its tooltip is `title ?? chatTip`. The document title is `${title ? title+' · ' : ''}${project} · Nota Bene`. The header shows `${model} · ${id8}` (the model comes from `system/init`).

## 3. Meters
- **Context:** `getContextUsage({ detail:'summary' })` with a 10 s timeout gives `{ used: totalTokens, max: rawMaxTokens || maxTokens, pct: percentage }`.
- **Limits:** `usage_EXPERIMENTAL_MAY_CHANGE_DO_NOT_RELY_ON_THIS_API_YET({ skipBehaviors:true })` with a 15 s timeout, throttled to once per 60 s. It gives `cost = session.total_cost_usd` and `limits = rate_limits_available ? { five_hour, seven_day } : null`, where each limit is `{ utilization (percent), resets_at (ISO) }`.
- **Schedule:** the first refresh 1.5 s after start, then every 5 min (which also resets the throttle), and after every `result`, `conversation_reset` and `compact_boundary`.
- **rate_limit_event:** when `rate_limit_info.rateLimitType` is `five_hour` or `seven_day` and utilization is not null, `pct = u<=1 ? u*100 : u` and `resets_at = resetsAt ? ISO(resetsAt*1000) : null`. Merge it in.
- **Formatting:** `fmtK(n) = n>=1e6 ? (n/1e6).toFixed(1)+'M' : n>=1e3 ? Math.round(n/1e3)+'k' : String(n)`. The meter bar is 44×4 px with `warn` at 60 and `hot` at 85. The cost shows only when there are no limits.
- **i18n (ru / en)**:
  - ctx: контекст / context
  - ctxTip(u,m): «${u} из ${m} токенов — дальше авто-сжатие» / "${u} of ${m} tokens — auto-compact after that"
  - h5: 5ч / 5h
  - h5Tip: «лимит плана за 5 часов» / "5-hour plan limit"
  - week: неделя / week
  - weekTip: «недельный лимит плана» / "weekly plan limit"
  - costTip: «стоимость этой сессии по API» / "API cost of this session"
  - resets(at): «сброс ${at}» / "resets ${at}", with at formatted `{weekday:'short', hour:'2-digit', minute:'2-digit'}`

## 4. Compact and clear
- **Client:** sends `{type:'command', name}`.
- **Server:** broadcasts a user event with the text `'/'+name` and pushes the plain string into the input stream with `priority 'next'`.
- **conversation_reset:** clears the history, saves the new id, sets the title to null, refreshes the stats.
- **Web on reset:** clears the feed and adds the line `cleared(at)`. On `compact_boundary` it adds `compacted(fmtK(pre_tokens), at)`.
- **i18n (ru / en)**:
  - compactTip: «Сжать контекст — агент кратко перескажет разговор и продолжит с пересказа (/compact)» / "Compact context — the agent summarizes the conversation and continues from the summary (/compact)"
  - clearTip: «Очистить контекст — новый разговор с нуля (/clear). Текущая сессия останется в «Сессии ▾»» / "Clear context — start a fresh conversation (/clear). The current session stays in “Sessions ▾”"
  - clearQ: «Очистить контекст и начать новый разговор?\n\nТекущая сессия сохранится — вернуться можно через «Сессии ▾».» / "Clear the context and start a new conversation?\n\nThe current session is kept — reopen it from “Sessions ▾”."
  - compacted(pre,at): «⇣ контекст сжат · было ${pre} токенов · ${at}» / "⇣ context compacted · was ${pre} tokens · ${at}"
  - cleared(at): «○ новый разговор · контекст очищен · ${at}» / "○ new conversation · context cleared · ${at}"

## 5. Plan card
- **Detection:** a permission event with `toolName === 'ExitPlanMode' && input.plan`.
- **Look:** teal border `oklch(0.78 0.12 185/.7)`; the plan is rendered markdown, max-height 60vh, scrollable, and commentable.
- **Answer:** both buttons send `{type:'permission', id, allow, input}`, and the server answers `{behavior:'allow', updatedInput: input}`.
- **Mode restore:** entering plan from X records X. Approving sets `restoreAfterPlan = X`. On the next non-plan echo that differs from it, the client sends `mode X` once.
- **i18n (ru / en)**:
  - planQ: «План готов — утвердить?» / "Plan ready — approve?"
  - approvePlan(m): «Утвердить · дальше «${m}»» / "Approve · continue in “${m}”"
  - keepPlanning: «Доработать план» / "Keep planning"

## 6. Mode
- **Modes and wiring:** `MODES = ['default','acceptEdits','plan','auto']`. A mode change calls `setPermissionMode(mode)` and is echoed as `{kind:'mode'}`. The server follows a `system` `init` or `status` message whose `permissionMode` differs.
- **Pill colours:** acceptEdits = primary, plan = teal 185, auto = yellow 80. The menu is 340 px, opens above the pill and marks the current mode.
- **i18n (ru / en)**:
  - modeTip: «Режим работы агента · Shift+Tab в поле ввода — следующий» / "Agent mode · Shift+Tab in the message field — next"
  - mode_default: Обычный / Default; desc: «Спрашивает разрешение на правки и команды» / "Asks before edits and commands"
  - mode_acceptEdits: Принимать правки / Accept edits; desc: «Правит файлы без вопросов, команды — с разрешения» / "Edits files without asking, asks before commands"
  - mode_plan: План / Plan; desc: «Только читает и думает, ничего не меняет; в конце покажет план на утверждение» / "Only reads and thinks, changes nothing; ends with a plan to approve"
  - mode_auto: Авто / Auto; desc: «Безопасное одобряет сам классификатор, спорное спрашивает» / "A classifier approves safe actions itself, asks about the rest"

## 7. Suggestions
- **Source:** the SDK option `promptSuggestions: true` yields `{type:'prompt_suggestion', suggestion}`.
- **Display:** the suggestion is the placeholder only when the field is empty and the agent is not busy. It is drawn at opacity .45 with padding-right 64 px, plus a `Tab ⇥` badge while the placeholder is shown.
- **Tab:** fills the field.
- **Clearing:** any user event (replayed included) and `conversation_reset` clear it.

## 8. Favicon
- **Colours:** `FAV = { idle:'#8b6cf2', work:'#8b6cf2', workHi:'#f0761f', wait:'#e5484d', done:'#22b45a' }`.
- **Shape:** an SVG with a 32×32 viewBox:
  - circle at (16,16), r=15.5;
  - white strokes, width 2.8, round caps and joins;
  - N: `M7.5 21.5v-11l6.5 11v-11`;
  - B: `M18 10.5h3.2a2.75 2.75 0 0 1 0 5.5H18z` and `M18 16h3.7a2.75 2.75 0 0 1 0 5.5H18z`.
- **State priority:**
  - wait: an unanswered permission;
  - work: busy, blinking every 700 ms between workHi and work;
  - done: a live result arrived while `document.hidden || !hasFocus()`, cleared on focus or visibility;
  - idle: otherwise.

## 9. Toasts
- **Dedup:** the key is `title+'\n'+msg`. A repeat shows ` ×N` and restarts the 15 s timer.
- **Interaction:** hovering clears the timer; × closes the toast.
- **Layout:** fixed at top 56 px, right 16 px, 380 px wide, with a `<pre>` capped at 160 px.
- **Title:** `serverError(w)`: «Ошибка сервера · ${w}» / "Server error · ${w}".

## 10. ↻ restart
In the prototype, `POST /restart` exits with code 75 and `ide.sh` relaunches with `--continue`. The rebuild does this in-process instead (ruling R-M4-1).
- **i18n (ru / en)**:
  - restart: «↻ Сервер» / "↻ Server"
  - restarting: перезапуск… / restarting…
  - restartTip: rewrite for R-M4-1: «Перезапустить агента и продолжить ту же сессию» / "Restart the agent and continue the same session"

## 11. Background-task line
- **Routing:** `system` messages with a `task_(started|progress|updated|notification)` subtype go to `onTask`. `background_tasks_changed` is not used.
- **Map entries:** `task_id → { desc, type, start, tokens, tool, summary }`.
  - started: skipped if `ambient || skip_transcript`; `desc = description || subagent_type || task_type || 'task'`; `start = event ts`.
  - progress: `tokens = usage.total_tokens`, `tool = last_tool_name`, `summary`.
  - updated: deletes the entry if the status is not running, pending or paused; otherwise updates desc from `patch.description`.
  - notification: deletes the entry.
- **Row:** ⚙ (pulsing) + desc + `time · fmtK(tokens) tok · tool`. Time is `Ns` under 60 s, else `m:ss`. The row tooltip is the summary or desc.
- **Ticking:** a 1 s interval runs only while tasks are live.
- **Replay:** clears the list first and does not render during the replay.
